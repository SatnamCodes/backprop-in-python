\section{The Core Idea: Sensitivity}
In Deep Learning, we don't just care about the answer. We care about \textbf{sensitivity}. 
If we have a result $L$, we want to know: \textit{"If I change input $a$ by a tiny bit, how much does $L$ change?"} 
This sensitivity is called the \textbf{Gradient} (\texttt{grad}).

\section{Step 1: The "Smart Box" (\texttt{Value} class)}
Every number in our program is wrapped in this class.

\begin{lstlisting}[language=Python]
class Value:
    def __init__(self, data, _children=(), _op=''):
        self.data = data           # The actual value (e.g., 2.0)
        self.grad = 0.0            # The Sensitivity (Starts at 0)
        self._prev = set(_children) # The "Parents" of this number
        self._backward = lambda: None # The recipe to calculate gradients
\end{lstlisting}

\section{Step 2: Defining the Example}
Let's use the exact numbers from the notebook:
$$L = (a \times b + c) \times f$$

\begin{lstlisting}[language=Python]
a = Value(2.0)
b = Value(-3.0)
c = Value(10.0)
f = Value(-2.0)

e = a * b      # Intermediate step
d = e + c      # Intermediate step
L = d * f      # Final result
\end{lstlisting}

\section{Step 3: Line-by-Line Walkthrough}

\subsection{The Forward Pass (Left to Right)}
This is just normal math, but the computer is building a "Family Tree" in the background.
\begin{enumerate}
    \item \textbf{\texttt{e = a * b}}: $2.0 \times -3.0 = -6.0$. Box \texttt{e} is created. It remembers its parents are \texttt{a} and \texttt{b}.
    \item \textbf{\texttt{d = e + c}}: $-6.0 + 10.0 = 4.0$. Box \texttt{d} is created. It remembers its parents are \texttt{e} and \texttt{c}.
    \item \textbf{\texttt{L = d * f}}: $4.0 \times -2.0 = -8.0$. Box \texttt{L} is the final result.
\end{enumerate}

\subsection{The Backward Pass (Right to Left)}
This is where the magic happens. We calculate \texttt{grad} (influence).

\begin{tcolorbox}[colback=blue!5!white,colframe=blue!75!black,title=The Goal]
We start at the end and set \texttt{L.grad = 1.0}. Then we work backward.
\end{tcolorbox}

\paragraph{1. Influence of $d$ and $f$ on $L$}
Since $L = d \times f$, if you increase $d$, $L$ changes by $f$. 
\begin{itemize}
    \item \texttt{d.grad = f.data * L.grad} $\rightarrow -2.0 \times 1.0 = \mathbf{-2.0}$
    \item \texttt{f.grad = d.data * L.grad} $\rightarrow 4.0 \times 1.0 = \mathbf{4.0}$
\end{itemize}

\paragraph{2. Influence of $e$ and $c$ on $d$}
Since $d = e + c$, addition just "passes" the influence back. 
\begin{itemize}
    \item \texttt{e.grad = 1.0 * d.grad} $\rightarrow 1.0 \times -2.0 = \mathbf{-2.0}$
    \item \texttt{c.grad = 1.0 * d.grad} $\rightarrow 1.0 \times -2.0 = \mathbf{-2.0}$
\end{itemize}

\paragraph{3. Influence of $a$ and $b$ on $e$}
Since $e = a \times b$, we use the multiplication rule again.
\begin{itemize}
    \item \texttt{a.grad = b.data * e.grad} $\rightarrow -3.0 \times -2.0 = \mathbf{6.0}$
    \item \texttt{b.grad = a.data * e.grad} $\rightarrow 2.0 \times -2.0 = \mathbf{-4.0}$
\end{itemize}

\section{Conclusion}
At the end, \texttt{a.grad} is \textbf{6.0}. This means if you increase \texttt{a} by 0.001, the final result \texttt{L} will increase by 0.006. The computer has successfully calculated the "Chain Rule" without us writing any calculus!
